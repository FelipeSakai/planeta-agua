# Login Operational Icons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Redesign the login as a compact operational entry screen and introduce restrained `lucide-react` icons in the login header and main navigation.

**Architecture:** Keep authentication behavior unchanged. Use the existing Next.js App Router files and shared UI components; add `lucide-react` as the only new dependency and import icons directly by name for bundle friendliness. Navigation items gain an icon component reference while labels remain the accessible source of truth.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, Tailwind CSS v4, Vitest, `lucide-react`.
